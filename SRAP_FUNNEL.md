# SRAP CONCEPTUAL MINI-FUNNEL & BRANDING

## THE IDENTITY: CHALAMANDRA MAGISTRAL
**Decodificadora Chola Malandra Fresa Salamandra**

SRAP is not a "self-help" app. It's a survival interface. The tone is brutal, dark, philosophical, and neon-industrial.

---

## CONCEPTUAL MINI-FUNNEL

1. **ATTENTION (The Hook)**
   - *Message:* "Your heart wants to change the world, your body begs for rest, and your head knows that tomorrow rent is due."
   - *Visual:* Glitchy text, dark background, 💀 icon.
   - *Goal:* Stop the scrolling by hitting the triple contradiction.

2. **IMMERSION (The Environment)**
   - *Message:* "Decide which center dies today so the others survive."
   - *Interaction:* The 3-Center Diagnosis (Head, Heart, Body).
   - *Goal:* Force the user into raw honesty.

3. **MICRO-GAME (The Loop)**
   - *Mechanic:* XP, Levels, and Achievements.
   - *Reward:* Leveling up from "Salamandra Perdida" to "Chalamandra Magistral".
   - *Goal:* Create a dopamine loop tied to existential awareness.

4. **VALUE (The Epiphany)**
   - *Output:* SRAP-AI analysis.
   - *Impact:* "Connection error. Even the AI has abandoned you today" (if failure) vs. Brutal truth (if success).
   - *Goal:* Provide a perspective the user was too afraid to see.

5. **AUTHORITY (The Frame)**
   - *Message:* "SRAP v2.0 - System Ready. Chalamandra Magistral Protocol Active."
   - *Goal:* Establish the SRAP methodology as a robust system, not a toy.

6. **PROOF (Social/Personal)**
   - *Visual:* Recent achievements and day streaks.
   - *Goal:* Show that the user is not alone in the abyss, and they are getting stronger.

7. **CTA (The Leap)**
   - *Action:* "SEAL REALITY" / "DECODE WOUND".
   - *Goal:* Convert reflection into a stored commitment.

8. **FOLLOW-UP (The Cycle)**
   - *Trigger:* "Come back tomorrow. The abyss never sleeps."
   - *Goal:* Retention via daily survival ritual.

## STRATEGIC SUGGESTIONS

### 1. SCALABILITY
- **Modular AI:** The `useAnalysis` hook and Supabase Edge Function are ready to swap Gemini for any other LLM.
- **Mobile First:** The UI uses Tailwind's responsive grid, ready for Capacitor/PWA conversion.
- **Course Integration:** Every "Synthesis" could be a lesson checkpoint in a larger "Decodificación Fresa" course.

### 2. GAMIFICATION
- **Secret Levels:** Hide levels beyond 10 for users with +100 days streak.
- **Sacrifice Multipliers:** Choosing the most "painful" sacrifice (detected by AI) gives 2x XP.
- **Community Bosses:** Shared challenges where users must collectively reach 10,000 XP to "unlock" a new philosophy module.

### 3. PERFORMANCE
- **Optimistic UI:** Update XP immediately in the UI while the database saves.
- **Caching:** Cache AI responses locally to avoid redundant API calls if the user doesn't change their synthesis.
